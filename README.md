## 🌟 核心特色

### 🎯 本体论驱动分析

使用**7 维度本体模型**深度标注每篇论文：

| 维度 | 说明 | 示例 |
|------|------|------|
| 记忆类型 | 记忆的本质分类 | 情景式/语义式/经验式 |
| 记忆结构 | 组织形式 | 图式/层次化/多图式 |
| 记忆操作 | 核心操作 | 编码/检索/整合 |
| 记忆载体 | 存储位置 | Token 级/外部数据库 |
| 功能定位 | 智能体角色 | 推理/规划/学习 |
| 模式识别 | 设计范式 | RAG/自进化/OS 启发 |
| 公理约束 | 底层原则 | 稳定性 - 可塑性/泛化性 |

### 📊 可视化 HTML 总结

每篇论文生成交互式 HTML 报告：
- ✅ Mermaid 架构图（居中显示）
- ✅ 本体论映射（7 维度标签）
- ✅ 6 维度评分雷达图
- ✅ 局限性分析区块
- ✅ 🌙深色/☀️浅色主题切换

### 🔄 持续更新

由 OpenClaw v8 模板驱动：
- 自动提取 arXiv 论文
- 生成本体论标注
- 输出 HTML 总结
- 每 10 篇优化本体模型
