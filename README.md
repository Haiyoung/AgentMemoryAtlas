## 🌟 项目亮点

### 🧠 本体论驱动的深度分析
使用**7维度本体模型**系统化标注每篇论文，构建领域知识图谱：
- **记忆类型**: 情景式/程序式/经验式/语义式
- **记忆结构**: 图式/层次化/混合式/向量式  
- **记忆操作**: 编码/检索/整合/反思/进化
- **功能定位**: 推理/规划/学习/决策
- **设计模式**: RAG/自进化/OS启发/经验驱动
- **公理约束**: 稳定性-可塑性/泛化性/效率
- **记忆载体**: Token级/外部数据库/参数级

### 📊 可视化论文总结
每篇论文生成交互式HTML报告，包含：
- ✅ Mermaid架构图（居中显示）
- ✅ 6维度综合评分
- ✅ 本体论7维度标签
- ✅ 局限性与未来方向
- ✅ 🌙深色/☀️浅色主题切换
