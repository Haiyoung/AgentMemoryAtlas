## 本体论映射 (Ontology Mapping)
基于 Agent Memory 领域本体模型的 7 维度标注

- **记忆类型**: Experiential Memory (经验记忆)
- **记忆结构**: Intent-Experience-Utility Triplet (意图-经验-效用三元组)
- **记忆操作**: Formation + Evolution + Retrieval
- **记忆载体**: Token-level (令牌级)
- **功能定位**: Runtime Continuous Learning (运行时持续学习)
- **使用模式**: Two-Phase Retrieval + Utility-Driven Update (两阶段检索 + 效用驱动更新)
- **验证公理**: Model-Memory Decoupling, Non-parametric RL on Memory

**领域贡献**: MemRL 将**强化学习理论**引入智能体记忆领域，提出了**非参数化自进化**的新范式。通过**意图-经验-效用三元组**结构和**两阶段检索机制**，该框架将记忆检索从被动语义匹配转化为主动决策过程，有效解决了现有方法无法区分高价值策略与噪声的根本问题。

## 核心主张（通俗易懂版）
- **🤔 问题是什么？** 当前AI智能体难以实现自进化：微调计算昂贵且容易灾难性遗忘，而现有基于记忆的方法依赖被动语义匹配，经常检索到噪声。
- **💡 解决方案是什么？** MemRL 提出非参数化方法，通过在情景记忆上进行强化学习来实现自进化，解耦稳定推理与可塑记忆。
- **🌟 核心优势是什么？** 通过两阶段检索机制（语义召回 + 价值感知选择）和效用驱动更新，MemRL 能够区分高价值策略与相似噪声，在不更新权重的情况下实现持续运行时改进。

## 实验结果
在四个多样化基准上，MemRL 显著优于现有方法：

**关键发现**: 
- **运行时学习**: 在累积成功率(CSR)上平均超越最强基线(MemP) +3.8%
- **迁移学习**: 在未见任务上平均超越最强基线 +2.8%
- **探索密集环境**: 在ALFWorld和OS任务上提升最为显著(+6.2%)
- **稳定性**: 有效防止灾难性遗忘，保持同步增长的学习曲线

## 局限性分析
- **轨迹长度限制**: 当前单步更新可能在长轨迹中引入高方差噪声
- **信用分配模糊**: 多个引用经验时的效用更新需要更精确的归因方法
- **任务相似性依赖**: 在低任务相似性环境中可能退化为反射式行为

## 未来研究方向
- **多步更新**: 探索多步更新或周期性记忆巩固机制
- **精确归因**: 开发基于Shapley值或值分解的信用分配方法
- **跨模型迁移**: 研究记忆在不同模型间的迁移能力
- **模块化扩展**: 支持多任务记忆合并和能力扩展
